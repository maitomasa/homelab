# My Homelab

Welcome to my home laboratory. This project is my personal playground for learning IT infrastructure by doing—building, breaking, and fixing things.

Under the hood, it's running **Ubuntu 25.10**. My goal is to build a setup that simulates a real production environment, but right here in my home network. Everything runs in Docker containers to keep things clean and portable.

## Why am I building this?
I don't just want to follow tutorials; I want to understand how things actually work. Through this lab, I'm learning:
* **Linux Administration:** Command line, security, and networking.
* **Infrastructure as Code (IaC):** The whole system is defined in this repo, so I can redeploy it anytime.
* **Containerization:** How Docker, proxies, and services talk to each other.

## What's inside?
Right now, I'm laying the foundation:
* `/infra` – Core services like **Nginx Proxy Manager** to handle traffic.
* `/apps` – Applications and other experiments (coming soon).
